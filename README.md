## 👨‍💻 About Me

I am a passionate **Systems, Desktop, and Multimedia Software Developer** and Engineering undergraduate at **Netaji Subhas University of Technology (NSUT)**. My work spans low-level multimedia processing, real-time AI frame generation, hardware EDA design environments, native cross-platform GUI engineering, and high-performance web applications.

- 🔭 **Currently Building**: High-performance native EDA tools with **Tauri v2 + Rust**, AI video frame interpolation engines for **mpv**, and modern academic portal platforms.
- 💡 **Core Expertise**: Real-time video rendering pipelines, VapourSynth/Vulkan shaders, SystemVerilog/VHDL simulation environments, full-stack web platforms, and Linux systems architecture.
- ⚡ **Philosophy**: Building software that is blazing fast, memory-safe, lightweight, and engineered with top-tier user ergonomics.
